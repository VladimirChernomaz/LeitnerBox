# LeitnerBox

Приложение-карточки для заучивания иностранных слов по системе Лейтнера (два списка: «ближний» и «дальний»), с раздельным прогрессом для прямого и обратного перевода.

## Как это работает
- **Ближний список** — слова, которые вы ещё нетвёрдо помните. Проверяются каждый день.
- **Дальний список** — хорошо запомненные слова. Проверяются реже (неделя → 2 недели → месяц).
- Ответили верно — слово продвигается дальше. Ошиблись — слово (если было в дальнем) возвращается в ближний, и добавляется повтор в сегодняшней сессии.
- У каждого слова два независимых прогресса: «иностранное → родной» и «родной → иностранное» — можно хорошо знать слово в одну сторону и путаться в другую.

Все слова хранятся только на телефоне (простой JSON-файл во внутренней памяти приложения), без сервера и аккаунта.

## Сборка
Собирается автоматически через GitHub Actions при каждом коммите в `main`
(см. `.github/workflows/build.yml`). Готовый APK — во вкладке **Actions** →
открыть последний зелёный запуск → раздел **Artifacts**.

Локально:
```
./gradlew assembleDebug
```
Результат: `app/build/outputs/apk/debug/app-debug.apk`.
